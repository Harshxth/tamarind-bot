# Saffron: Tamarind Table's AI Dining Assistant

A Botpress AI chatbot for Tamarind Table, the fictional Hyderabadi restaurant from ISM 6225 Assignment 1, embedded in a single page (`mybot.html`) on GitHub Pages.

**Live page:** https://harshithgujjeti.com/tamarind-bot/mybot.html

| File | What it is |
| --- | --- |
| `mybot.html` | The single webpage: bot purpose, sample questions, the menu/hours/policies the bot answers from, and the embedded Botpress webchat |
| `botpress/tamarind-table-knowledge-base.txt` | Document uploaded to the bot's Botpress knowledge base (18 dishes, hours, diet reference, reservations, catering, deals) |
| `botpress/bot-instructions.txt` | The bot's persona and rules, pasted into Botpress Studio |

Plain HTML, CSS and JavaScript in one file, no build step. All restaurant data is sample data.
